**Tech Stack:**

`React` `Vite` `Node.js` `Express.js` `MongoDB` `Gemini API` `JWT` `Terraform` `GitHub Actions` `Playwright`

### Features

- ☁️ Intelligent AWS architecture recommendations based on workload requirements
- 🏗️ Interactive branching architecture diagrams with topological layouts
- 📊 AWS Well-Architected Framework evaluation across all 6 pillars
- 🤖 Gemini-powered AI assistant and free-text project requirement intake
- 🔍 AWS service catalog featuring 25 services
- ⚖️ Side-by-side AWS service comparisons (Lambda vs EC2, ECS vs EKS, RDS vs Aurora)
- 💰 Interactive AWS cost estimation
- 🛠️ Terraform infrastructure scaffold generation with security-focused defaults
- 🔐 JWT-based authentication and saved recommendations
- 📄 PDF, JSON, SVG, PNG, and Mermaid architecture exports
- 🌍 High Availability and Disaster Recovery architecture modes
- 📈 Architectural pre-mortem and production failure-mode analysis
- 🧪 Unit, integration, and Playwright end-to-end testing
- 🔄 GitHub Actions CI pipeline for automated testing and builds
- 🚀 Deployed using Vercel, Render, and MongoDB Atlas
